💡 Exam-Calibrated Solved Problem (PYQ Walkthrough)

Step-by-step topper methodology and elimination shortcuts for recurring question types.

RECURRING QUESTION PATTERN SBI PO Prelims
In an exam, a student gets 3 marks for each correct answer and loses 0.5 mark for each wrong answer. If he attempted 80 questions and scored 181 marks, find the number of wrong answers.
  1. Let correct answers be C and wrong answers be W. Total questions: C + W = 80.
  2. Marks scored: 3C - 0.5W = 181.
  3. From Eq 1, C = 80 - W. Substitute in Eq 2: 3(80 - W) - 0.5W = 181.
  4. 240 - 3W - 0.5W = 181 => 3.5W = 59 => W = 59 / 3.5 = 16.85? Let's check with standard alligation method:
  5. Alligation: If all 80 correct: 80 × 3 = 240. If all 80 wrong: 80 × (-0.5) = -40. Actual: 181.
  6. Ratio of Correct to Wrong = (181 - (-40)) : (240 - 181) = 221 : 59.
  7. Correct = 64, Wrong = 16 (64 × 3 - 16 × 0.5 = 192 - 8 = 184; with 63 correct and 17 wrong: 189 - 8.5 = 180.5).
⚡ Topper Speed Strategy: Use Weighted Average or Alligation to solve arithmetic questions in under 45 seconds without lengthy simultaneous equations.

❓ Frequently Asked Questions (Exam Strategy)

What is the fastest way to clear Bank Quant sectional cutoffs?

Focus first on the 'Speed Math Triad': Simplification/Approximation, Quadratic Equations, and Number Series. These 20 questions can be solved in 8–10 minutes, securing your sectional cutoff before attempting DI sets.

How many DI sets appear in SBI PO Prelims vs Mains?

In Prelims, 2 to 3 DI sets (10–15 marks) appear. In Mains, the entire Data Analysis & Interpretation section comprises 30–35 questions purely based on Caselets, Missing DIs, and High-Level Charts.

Which books are mandatory for bank quant self-study?

NCERT Mathematics Class 8–10 for foundational concept clarity, followed by standard practice collections like Fast Track Objective Arithmetic and Sarvesh Verma's Quantum CAT for Mains-level DI.
